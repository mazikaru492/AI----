# AI問題変換

学校や塾で使う問題作成を、日々の運用に乗せやすい形で補助する Next.js アプリです。
現在は「数学 類題変換」と「英語 単語穴埋めテスト」の2機能を使えます。

## 現在できること

| 機能                  | 入力                                  | できること                                                                       | 出力                                      |
| --------------------- | ------------------------------------- | -------------------------------------------------------------------------------- | ----------------------------------------- |
| 数学 類題変換         | 問題画像（カメラ撮影 / ファイル選択） | 画像内の数字を検出し、式や問題文の数字だけを置き換えた類題画像を作成             | PNG画像をダウンロード                     |
| 英語 単語穴埋めテスト | Excel / CSV、範囲指定（例: `A2:A50`） | 指定範囲の単語を抽出し、例文・穴埋め文・4択つきの問題を自動作成                  | `WordTest` シート付き XLSX をダウンロード |
| 共通機能              | -                                     | システム選択画面で機能切り替え、履歴表示、利用回数の表示（Supabase設定時は保存） | 画面上で確認                              |

## 使い方

### 1. 共通フロー

1. アプリを開く
2. システム選択画面で使いたい機能を選ぶ
3. 各機能の入力を設定して実行
4. 生成結果をダウンロードする

### 2. 数学 類題変換

1. 問題画像を読み込む（撮影またはファイル選択）
2. `類題を生成` を押す
3. 処理後の画像を確認し、`画像をダウンロード` を押す

補足:

- 画像が大きい場合は自動で圧縮して処理します
- 数字が検出できない画像はエラー表示になります
- 変換件数は画面上部で確認できます

### 3. 英語 単語穴埋めテスト

1. Excel / CSV ファイルを選択
2. 単語範囲を入力（例: `A2:A50`）
3. 必要ならシート名を入力（未入力なら先頭シート）
4. 出題数（1〜50）を指定
5. `単語テストを生成してExcel出力` を押してダウンロード

補足:

- 範囲は `A2:A50` 形式のみ
- 指定範囲は最大 2000 セル
- 空セルや重複語は整理してから出題に使います

## セットアップ

### 前提

- Node.js 20 以上
- npm

### インストール

```bash
npm install
```

### 開発サーバー起動

```bash
npm run dev
```

`http://localhost:3000` を開いて動作確認してください。

## 環境変数

`.env.local` に設定します。

| 変数名                                          | 用途                       | 必須                       |
| ----------------------------------------------- | -------------------------- | -------------------------- |
| `ZAI_API_KEY`                                   | 数学の数字検出API          | 数学機能を使う場合は必須   |
| `GOOGLE_GEMINI_API_KEY` または `GEMINI_API_KEY` | 英語テスト生成（Gemini）   | 英語機能を使う場合は必須   |
| `NEXT_PUBLIC_SUPABASE_URL`                      | 利用回数・履歴の保存       | 任意                       |
| `NEXT_PUBLIC_SUPABASE_ANON_KEY`                 | 利用回数・履歴の保存       | 任意                       |
| `MICROCMS_SERVICE_DOMAIN`                       | 制作者情報取得（microCMS） | 制作者表示を使う場合は必須 |
| `MICROCMS_API_KEY`                              | 制作者情報取得（microCMS） | 制作者表示を使う場合は必須 |
| `MICROCMS_DRAFT_KEY`                            | 下書きコンテンツ取得       | 任意                       |
